## What AlgTrain Does

AlgTrain gives speedcubers a dedicated browser workspace for studying Rubik's Cube algorithms. Its practice material is organized around three key groups - PLL, OLL, and CLL - so learners can work through cases in a structured way and revisit them regularly.

Because it runs on the web, the trainer can be used without installing a separate desktop application. The focused interface helps users spend their practice time recognizing cases, reviewing sequences, and improving execution consistency.

## Getting Started

### Open the hosted version

Launch the current web build here:

[Launch AlgTrain](https://kellymasonjgom1511.github.io/algtrain-cubing-algorithm-hub/)

### Run the project locally

Clone the repository and enter its directory:

```bash
git clone https://github.com/kellymasonjgom1511/algtrain-cubing-algorithm-hub.git
cd REPO
```

You can then open the primary HTML file in a modern browser. Alternatively, serve the project directory through a local static web server.

For instance:

```bash
python -m http.server
```

Once the server is running, open `http://localhost:8000` in your browser.

## Practice Workflow

1. Start AlgTrain in your browser.
2. Pick a study group: PLL, OLL, or CLL.
3. Choose a case or another available practice option.

6. Move between categories when you want a more balanced session.
